Quick Start Guide

  1. Start by visiting Kibana to set up your data views
  2. Visit the Traffic Generator to start simulating APT activity
  3. Check the Zeek Viewer for real-time network monitoring
  4. Return to Kibana to hunt for suspicious patterns using the scenarios below
  5. Logs are being generated continuously - start hunting immediately!
